# Umang Health Innovation — CaTS website

Pages (from the wireframe PDF): Home (`/`), Breast Screening (`/breast-screening`), Booking & Payment (`/booking`).

```bash
npm install      # install dependencies
npm run dev      # start the dev server
npm run build    # production build
npm test         # run booking rule tests
```

Structure: `src/components` (Navbar, Footer, Hero, Card, Accordion, StepForm, ThemeToggle), `src/routes` (pages), `src/styles.css` (CSS variables + plain CSS classes), `src/data` (site content), `src/lib/booking.ts` (prices & validation).
